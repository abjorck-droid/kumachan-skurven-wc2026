## What's been decided (locked)

### Stack
- **Frontend:** static HTML/JS on Cloudflare Pages (free account already set up by Andreas, subdomain decision pending).
- **Backend:** Airtable, separate base from the Dominion tracker. Schema in `02_Airtable_schema.md`.
- **Data source:** API-Football (api-sports.io, free tier — 100 calls/day). World Cup 2026 is `league=1`, `season=2026`. Spike confirmed full coverage.
- **Poller:** GitHub Actions cron, two workflows (`scoreboard-poll` every 15 min during match windows, `leaderboards-poll` daily). See `01_API_findings.md`.

### Game mechanics
All in `03_Scoring_spec_v0.1.md`. The locked decisions:

- **Confidence tokens (the spine of the game):** each player starts with 4× Double (2×), 2× Triple (3×), 1× All-In (5×). Attached one per prediction. **Soft downside** — wrong pick with token attached = 0 points but token consumed.
- **Side games — full sicko mode:** Golden Boot (60), Golden Glove (60), Dark Horse with escalating ladder (25/75/200/500/1000, non-cumulative), First Red Card (30), First Own Goal (40), Total Tournament Goals (30, closest without going over), per-group top scorer (15 each, 12 groups).
- **Per-match bonus bets — co-participation rule:** a bonus bet on a match only scores if BOTH players opted in (any bet type, doesn't have to mirror). Anti-carpet-bomb mechanic; opt-in is blind because bonus bets are hidden until kickoff.
- **Beat-Cal bonus:** +3 points per match where one player gets the outcome right and the other doesn't.
- **Mulligan:** 1 per player, used in window between group stage end and R32 start. Re-pick one bracket slot. Both original and replacement score at 50% value.
- **Pundit Notes:** optional one-line note per prediction. Locked with the pick. Revealed only after the prediction resolves.

### Visibility rules
- Private until lock.
- At lock: everything visible *except* Pundit Notes (revealed at prediction resolution) and per-match bonus bets (revealed at that match's kickoff, gated client-side via known kickoff times).
- Mulligans visible the instant they're used.

### Aesthetic
- Broadcast TV direction, near-black bg (`#0a0b10`), magenta accent (`#ff1c5c` — open to coral or crimson alternative if we want a different register).
- Typography: Antonio (condensed sans, labels), Cormorant Garamond (serif numerals), Architects Daughter (handwriting, for Pundit Notes).
- Player accent colors: Andreas teal (`#4ec9b0`), Cal purple (`#c586c0`).
- H2H header on every page with running scores + token reserves + current pick streak.

### Dropped from v1
- Vote of No Confidence (didn't work cleanly with soft downside).
- Shadow Bets (held for pre-tournament review if the game feels too static).
- Brier scoring, streak multipliers, underdog odds-based multipliers, pre-tournament reactive mechanics.
