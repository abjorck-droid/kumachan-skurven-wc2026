1. **Pick-entry Knockouts tab rebuilt** (`site/index.html`). Free-form ladder dropdowns are gone.
   New flow: **Group finishes** (12 cards, tap teams in 1-2-3 finishing order; tap a ranked team
   to undo from there) → **Best thirds** (pick 8 of the 12 third-placed teams; selection is by
   group letter, so a reshuffled 3rd keeps the slot and swaps the team) → **Bracket** (R32 → R16
   → QF → SF → Final, tap the winner of each tie; the advancer earns the next round's slot and
   gets the token select + pundit note inline). Dark Horse unchanged.
   - **Storage unchanged**: the tree writes the same scored `bracket_slot` rows (R16-1..16,
     QF-1..8, SF-1..4, F-1..2, Champion) the spec scores as order-free sets, plus **13 unscored
     `bracket_struct` rows** persisting the generating structure: `group_order|A`..`L`
     (predicted_text = "MEX,KOR,RSA" codes in finish order) and `thirds_advance` (letters).
     Engine, live board, lock semantics, scoring spec — all untouched (engine dispatches on
     prediction_type and ignores `bracket_struct`; `bracket_tier()` returns None for struct keys).
   - **House R32 template** (cosmetic — sets score, not positions; UI says so): winners A–H face
     the 8 advancing thirds in group-letter order; winners I–L face runners-up A–D; runners-up
     E..L pair off E-F, G-H, I-J, K-L. Bracket above is strict halving (R16 match k = winners of
     R32 matches 2k-1/2k, etc.) so every team's path is fixed by its R32 slot.
   - **Surgical cascade** (`pruneAssign`): all slots re-derived from team identity on every
     structural change. A team that merely moves position keeps its pick **and its token/note**
     (they ride by team, not slot). A team that drops out clears everywhere above (token refunds
     to reserve). If two picked teams now collide on one slot (they meet earlier than before),
     **both void** and the user re-decides that tie.
   - The old coherence warnings + duplicate guard are deleted (the tree can't be incoherent);
     the Review tab now shows a completeness checklist (12 groups / 8 thirds / 31 slots).
   - **Legacy picks**: on load, bracket slot rows without structure rows = free-form leftovers →
     dropped client-side, deleted on next save.
   - Test hooks: `window.__T` exposes the pure functions + state setters for the stub-DOM suite.
